# Contributing to Mermaid

Please see our comprehensive [Contributing Guidelines](./packages/mermaid/src/docs/community/contributing.md) for details on how to get started, install requirements, and submit pull requests.

## Fork-specific

This repository is a long-lived fork of [mermaid-js/mermaid](https://github.com/mermaid-js/mermaid).
Merging upstream changes has its own runbook — see
[`.github/fork-sync/GUIDE.md`](./.github/fork-sync/GUIDE.md) — and is automated by
[`sync-oss-develop.yml`](./.github/workflows/sync-oss-develop.yml).
